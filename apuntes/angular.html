Apuntes Angular CLI Cheat Sheet

← Volver a Apuntes

1. Instalación y Diagnóstico

Instalación global de Angular CLI y comprobación de versiones instaladas:

# Instalar Angular CLI globalmente
npm install -g @angular/cli

# Verificar versiones de Angular, Node y TypeScript
ng version

2. Creación y Servidor de Desarrollo

Crear un nuevo proyecto estándar o con opciones configuradas:

# Proyecto nuevo básico
ng new mi-proyecto

# Con enrutador y estilos SCSS
ng new mi-proyecto --style=scss --routing

Ejecutar servidor local de pruebas:

# Levantar servidor en http://localhost:4200
ng serve

# Levantar, abrir navegador y especificar puerto
ng serve -o --port 4200

3. Generación de Elementos (ng generate / ng g)

Generación de componentes:

# Componente estándar en carpeta específica
ng g c components/mi-componente

# Componente Standalone explícito
ng g c components/mi-componente --standalone

# Sin archivo de testing (.spec.ts)
ng g c components/mi-componente --skip-tests

# Con template y estilos integrados en el .ts
ng g c components/mi-componente --inline-template --inline-style

Generación de servicios, modelos y protecciones:

# Servicio inyectable
ng g s services/data

# Interfaz / Modelo de TypeScript
ng g interface models/usuario

# Guard funcional para protección de rutas
ng g guard guards/auth

4. Compilación y Despliegue (Build)

Generar bundle optimizado de producción en /dist:

# Build de producción estándar
ng build

# Build adaptado para subcarpetas (GitHub Pages)
ng build --base-href /nombre-del-repo/

5. Librerías y Actualizaciones

Añadir dependencias compatibles y actualizar versión del framework:

# Integrar librerías mediante schematics
ng add @angular/material

# Revisar librerías desactualizadas
ng update

# Actualizar core y CLI a la última versión
ng update @angular/core @angular/cli
